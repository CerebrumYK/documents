# Пакет ТЗ для Codex

Исторический состав пакета:

- `TZ_Actor_Website_Codex.md` — полное техническое задание;
- `AGENTS.md` — постоянные правила для Codex;
- `CODEX_TASKS.md` — поэтапный план реализации;
- `TZ_Actor_Website_Codex.docx` — версия ТЗ для чтения и согласования.

Исходная рекомендация размещения:

```text
AGENTS.md                  -> корень implementation repository
CODEX_TASKS.md             -> корень implementation repository
TZ_Actor_Website_Codex.md  -> docs/TZ.md
```

Исходную актёрскую анкету требовалось держать локально в `private-import/` и обязательно исключить каталог из Git.

Первоначальный пакет также прямо рекомендовал не просить Codex реализовать весь проект одним запросом.

> Historical source note: текущий documentation repository использует DOC-003 governance, DOC-206 implementation sequencing и DOC-223 Codex execution plan. Этот файл сохранён исключительно как provenance исходного пакета.
